Featured Projects

Full-stack web applications, database matching platforms, and AI systems

1. SkillSphere – Peer-to-Peer Skill Exchange Platform

A database-backed platform designed to connect students by complementary skill sets using an automated matching engine and transaction-safe bookings.

  • Designed a normalized 8-table MySQL schema with 1:1, 1:M, and M:N relationships, enforced via foreign keys, UNIQUE, and CHECK constraints.
  • Built a skill-matching engine using stored procedures (sp_find_matching_partners) to pair students based on complementary skill needs.
  • Implemented transaction-safe session booking and 4 triggers for automated notifications and profile scoring.
  • Created 3 views and 11 indexes to optimize reporting and query performance.
  • Python
  • MySQL
  • Stored Procedures
  • Triggers & Views

2. Talk To Heal – AI Voice Healthcare Triage System

Multilingual voice-and-text healthcare symptom checker web application built for the Srishti Hackathon.

  • Built a multilingual (8-language) voice-and-text symptom checker using Web Speech API for speech-to-text and text-to-speech.
  • Designed a diagnostic engine classifying symptoms across 8 medical departments with 4-level severity triage.
  • Built the front-end UI and a Flask backend serving diagnosis logic via REST API.
  • HTML5 / CSS3
  • JavaScript
  • Web Speech API
  • Python Flask

3. MPLADS Sentinel – AI Risk Intelligence System

Explainable AI risk-scoring platform for government infrastructure project monitoring (Smart India Hackathon 2026 Qualifier).

  • Designing an explainable AI risk-scoring system using rule-based checks, financial anomaly detection, and NLP duplicate-work detection.
  • Architected a 5-pillar composite risk engine producing an auditable evidence card per flagged case.
  • Built interactive prototype dashboards and workflow visualizations for the SIH presentation.
  • React / Next.js
  • FastAPI
  • PostgreSQL
